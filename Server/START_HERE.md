# ATM9 Control — исходники сайта

React-панель мониторинга Mekanism, AE2 и ComputerCraft.

## Запуск

1. Установите Node.js 22.13+ и pnpm 11.25+.
2. В каталоге проекта выполните `pnpm install`.
3. Запустите `pnpm dev` и откройте адрес, который покажет Vite.
4. Для производственной сборки выполните `pnpm build`.

По умолчанию панель показывает демонстрационные данные. Для реальных показаний откройте «Настроить подключение» и укажите URL собственного HTTP-шлюза. Формат запросов, полей и методов CC описан в `GATEWAY.md`. Шлюз и программа внутри Minecraft в архив не входят.

Служебный идентификатор опубликованного сайта исключён из архива; проект можно разворачивать отдельно.
